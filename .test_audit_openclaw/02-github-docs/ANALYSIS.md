## Top 5 most surprising features

1. **VoiceClaw real-time WebSocket brain** at `/voiceclaw/realtime` — Gemini Live audio chats directly with OpenClaw, OpenClaw exposes its full tool surface to Gemini Live and returns immediate `working` results so voice latency stays low while tools run async.

2. **Formal verification with TLA+/TLC** for security claims (gateway exposure, node exec pipeline approvals tokenization, pairing TTL/cap concurrency, mention bypass, routing precedence) — every claim has a paired **negative model** producing a counterexample. Models live at `vignesh07/openclaw-formal-models`.

3. **Broadcast groups** — `broadcast: { "<peer-id>": ["alfred", "baerbel", "code-reviewer"] }` runs N agents in parallel/sequential on the same WhatsApp peer, each with isolated session/tools/personality/model. WhatsApp-only currently, Discord/Telegram/Slack planned.

4. **OpenAI-compatible HTTP API by default** at `/v1/chat/completions`, `/v1/responses`, `/v1/embeddings`, `/v1/models` — Open WebUI / LibreChat / RAG pipelines treat any OpenClaw Gateway as a model provider, returning `openclaw/default` and `openclaw/<agentId>` as model IDs.

5. **Lobster typed workflow runtime with resumable approval gates** — `.lobster` YAML files run multi-step pipelines (`stdin: $step.json`, `condition: $step.approved`, `approval: required`); halt returns a `resumeToken`; LLM-task plugin gives schema-validated structured JSON output inside the deterministic flow.

## 1. Elevator pitch

OpenClaw is a **self-hosted, MIT-licensed TypeScript "any OS / any platform" gateway** that turns a single long-running process on your own machine into the bridge between (a) every chat app you already use — Discord, Telegram, WhatsApp, iMessage, Signal, Slack, Microsoft Teams, Matrix, Google Chat, Feishu, LINE, WeChat, Mattermost, Nostr, Twitch, IRC, QQ, Zalo, Synology Chat, Nextcloud Talk, Tlon, BlueBubbles, Voice Call, plus a built-in WebChat — and (b) one or many AI coding/personal-assistant agents driven by 50+ LLM providers (Anthropic, OpenAI, Google, Bedrock, OpenRouter, DeepSeek, Mistral, Moonshot, Z.AI, Groq, xAI, Ollama, vLLM, SGLang, LM Studio, etc.). The lobster-mascotted project is the third molt of "Warelay → Clawd → Molty → OpenClaw" (Jan 30 2026); its philosophy is `OPEN + CLAW = open source, open to everyone, your assistant, your machine, your rules` (`start/lore.md`). Run `openclaw onboard --install-daemon`, message from any of 25+ supported channels, and the same agent answers — with persistent memory in plain Markdown files (`AGENTS.md`, `SOUL.md`, `MEMORY.md`, `memory/YYYY-MM-DD.md`), tool-use, sandboxing, multi-agent routing, cron-driven autonomy, ACP harnesses (Claude Code, Codex, Gemini CLI, Cursor, OpenCode, Copilot, Droid), MCP server bridges, voice wake on macOS, paired iOS/Android nodes for camera/screen/location/Canvas, and a browser Control UI dashboard. It is explicitly a **personal-assistant trust model** (one trusted operator boundary per gateway), not a hostile-multi-tenant system, and it stays operator-owned: every credential, transcript, and memory file lives on disk under `~/.openclaw/`.

## 2. Core architecture

**Gateway** (`concepts/architecture.md`, `gateway/index.md`) — Single always-on Node process (Node 24 recommended, 22.14+ supported). Multiplexes one port (default `127.0.0.1:18789`) for: WebSocket control/RPC, OpenAI-compatible HTTP API (`/v1/models`, `/v1/embeddings`, `/v1/chat/completions`, `/v1/responses`, `/tools/invoke`), browser Control UI, Canvas host (`/__openclaw__/canvas/`, `/__openclaw__/a2ui/`), VoiceClaw real-time WebSocket (`/voiceclaw/realtime`), webhooks (`/hooks/...`), supervisor (LaunchAgent / systemd / Scheduled Task). Hot-reload watches `~/.openclaw/openclaw.json` and atomically swaps last-known-good config; invalid edits are quarantined as `.clobbered.*`.

**Agent runtime** (`concepts/agent.md`, `concepts/agent-loop.md`) — Embedded Pi-coding-agent core + OpenClaw-owned session/skill/channel/tool layer. Each agent has a workspace (`~/.openclaw/workspace`) with 8+ injected bootstrap files. Agent loop: intake → context assembly → model inference → tool execution → streaming reply → JSONL transcript at `~/.openclaw/agents/<agentId>/sessions/<sessionId>.jsonl`. Plugin hook surface includes `before_model_resolve`, `before_prompt_build`, `before_agent_reply`, `before_agent_finalize`, `agent_end`, `before_compaction`, `before_tool_call`, `after_tool_call`, `tool_result_persist`, `message_received`, `message_sending`, `before_install`, `gateway_start/stop`, `session_start/end`. Run timeouts: 48-hour agent, 30s `agent.wait`.

**Channels** (`channels/index.md`) — Each channel is a plugin (bundled or external) implementing `ChannelPlugin` with adapters for setup, security/DM-policy, pairing, threading, outbound, heartbeat-typing, mention-gating, native approvals, and message-tool action discovery. Inbound routing is deterministic and most-specific-wins: peer → parentPeer → guildId+roles → guildId → teamId → accountId → channel → default.

**Tools** (`tools/index.md`) — Built-in: `exec`/`process` (with PTY, sandbox/gateway/node hosts), `code_execution`, `browser` (managed Chrome + remote CDP + Browserless/Browserbase + Chrome MCP), `read`/`write`/`edit`/`apply_patch`, `message`, `canvas`, `nodes`, `cron`, `gateway` (owner-only config.patch/apply/update.run), `image`/`image_generate`, `music_generate`, `video_generate`, `tts`, `pdf`, `web_search`/`x_search`/`web_fetch`, `memory_search`/`memory_get`, `sessions_*`, `subagents`, `agents_list`, `session_status`, `tokenjuice`, `lobster`, `llm-task`. Tool policy: `tools.profile` (`full`/`coding`/`messaging`/`minimal`), `tools.allow`/`deny`, group shorthands.

**Nodes** (`nodes/index.md`) — Companion devices (macOS menu-bar, iOS, Android, headless Linux/Windows) connect with `role: node` and a device pairing handshake. Expose `canvas.*`, `camera.*`, `screen.record`, `system.run`/`which`/`notify`, `device.*`, `notifications.*`, `photos.latest`, `contacts.*`, `calendar.*`, `callLog.search`, `sms.*`, `motion.*`, `location.get`. Per-node exec approvals at `~/.openclaw/exec-approvals.json`.

**Sessions and queue** (`concepts/session.md`, `concepts/queue.md`) — Sessions keyed by `agent:<agentId>:<channel>:<kind>:<id>[:thread:<id>][:topic:<id>]`. DM scope: `main` (default), `per-peer`, `per-channel-peer`, `per-account-channel-peer`. Lifecycle: daily reset at 4 AM local, optional idle reset, manual `/new`/`/reset`. Queue lanes: per-session (1 active), main (default 4), subagent (default 8), `cron`, `cron-nested`, `nested`. Queue modes: `collect` (default), `steer`, `followup`, `steer-backlog`, `interrupt`. Compaction is automatic with provider overflow detection or manual `/compact`.

**Memory subsystem** (`concepts/memory.md`) — Plain markdown is the source of truth: `MEMORY.md` durable, `memory/YYYY-MM-DD.md` daily, `DREAMS.md` for dreaming. Three exclusive-slot backends: **builtin** (SQLite + keyword/vector/hybrid search; default), **QMD** (local-first sidecar with reranking + cross-agent collections), **Honcho** (AI-native cross-session). **Memory Wiki** companion plugin compiles knowledge into a provenance-rich vault with `wiki_search`/`wiki_get`/`wiki_apply`/`wiki_lint`.

**Dreaming subsystem** (`concepts/dreaming.md`) — Opt-in background memory consolidation, default cron `0 3 * * *`. Three phases: **Light** (stage), **Deep** (rank by 6 weighted signals — frequency 0.24, relevance 0.30, query-diversity 0.15, recency 0.15, consolidation 0.10, conceptual richness 0.06 — and promote into `MEMORY.md`), **REM** (themes/diary). Grounded historical backfill via `memory rem-backfill`.

## 5. Notable / non-obvious features

- **Single port multiplexing** — Gateway runs WebSocket RPC, Canvas, A2UI, OpenAI HTTP API, OpenResponses, tools-invoke, Control UI, webhooks, VoiceClaw real-time on the same port (default 18789).
- **OpenAI-compatible by default** — `/v1/chat/completions`, `/v1/responses`, `/v1/embeddings`, `/v1/models` work out-of-box. Returns `openclaw/default` and `openclaw/<agentId>` as model IDs.
- **VoiceClaw Gemini Live brain** at `/voiceclaw/realtime` — desktop voice client → Gemini Live → OpenClaw tools, returning `working` results to keep latency low.
- **Formal verification** with TLA+/TLC + paired negative counterexample models for every claim.
- **Cron + ACP + Lobster + LLM-task = AI-native auto-research** — durable resumable approval-gated autonomous pipelines.
- **Standing orders** in `AGENTS.md` are persistent agent authority contracts (Authority/Trigger/ApprovalGate/EscalationRules).
- **Skill bundles for Codex/Claude Code/Cursor** install via `openclaw plugins install ./bundle`; map skills/commands/MCP/LSP/settings into native features.
- **Tool result middleware** — `registerAgentToolResultMiddleware` rewrites tool output before model feedback (used by tokenjuice).
- **iOS pairing through Telegram** — `/pair` returns base64 setup-code, no QR.
- **Relay-backed APNs push** for distributed iOS builds — `gateway.push.apns.relay.baseUrl`.
- **Auto-regenerated `gateway.auth.token`** when browser control is enabled and no auth exists.
- **Compaction can use a different model** — `agents.defaults.compaction.model`.
- **Successor transcripts** — `truncateAfterCompaction: true` creates new active JSONL from summary + state + tail.
- **Pluggable compaction provider** — `registerCompactionProvider()` with built-in fallback.
- **Multi-agent broadcast** on a single peer — N agents in parallel/sequential per peer.
- **Plugin lookup table** — metadata-only Gateway-startup index for cold-path performance.
- **Native Codex hook relay** — plugin `before_tool_call` can block Codex-native shell/apply-patch tools.
- **Inline `llm-task` in Lobster** — schema-validated structured JSON inside deterministic workflow.
- **Sub-agent context fork** — `sessions_spawn({context: "fork"})` branches transcript into child.
- **Cross-agent QMD memory** — agent A searches agent B's transcripts via `extraCollections`.
- **Symlink-safe sandbox bind validation** — re-checks deepest existing ancestor.

## 6. Power-user patterns

- **Auto-research loop** — cron → isolated session → Lobster pipeline → llm-task → if better than baseline, write to `MEMORY.md`.
- **Plan-mode workflow** — `BOOT.md` hook on gateway start; first session loads `MEMORY.md` + today's daily; `/think:high` for big tasks; `/elevated full` only for trusted ops.
- **Multi-persona delegate org** — multiple `agents.list[]` entries with hard blocks in `SOUL.md`, M365/Workspace tier permissions, audit logging.
- **Skill chaining via `context: fork`** — orchestrator skill runs N sub-skills sequentially, each writes structured output for the next.
- **Stochastic multi-agent consensus** — broadcast to N agents with different `SOUL.md` personalities, synthesize with another agent.
- **Mirror+remote OpenShell sandbox** — local edits sync into remote GPU sandbox, sandbox writes sync back.
- **Adversarial code review** — primary writes; sub-agent with attack-focused `SOUL.md` reviews via `sessions_spawn({context: "fork", runtime: "acp", agentId: "codex"})`.
- **GitHub trending → Memory Wiki** — daily cron → web_search → llm-task scores → wiki ingest.
- **Gmail PubSub → ACP** — Gmail → Tailscale Funnel → cron-style isolated agent run on Claude Code.
- **Two-phase compaction** — cheap Ollama for summaries, Opus 4.7 for actual reasoning.
- **Cross-model adversarial review** — bind one Discord channel to native Codex, another to Claude ACP.

From `index.md`:
> OpenClaw is a **self-hosted gateway** that connects your favorite chat apps and channel surfaces to AI coding agents. Self-hosted: runs on your hardware, your rules. Multi-channel: one Gateway serves built-in channels plus bundled or external channel plugins simultaneously. Agent-native. Open source, MIT licensed.

From `gateway/security/index.md`:
> **Personal assistant trust model.** This guidance assumes one trusted operator boundary per gateway… OpenClaw is **not** a hostile multi-tenant security boundary.
>
> Most failures here are not fancy exploits — they're "someone messaged the bot and the bot did what they asked." OpenClaw's stance: Identity first → Scope next → Model last (assume the model can be manipulated; design so manipulation has limited blast radius).

From `concepts/memory.md`:
> OpenClaw remembers things by writing **plain Markdown files** in your agent's workspace. The model only "remembers" what gets saved to disk — there is no hidden state.

The recurring theme is **operator sovereignty + transparency**: every secret, every transcript, every memory note lives on disk under `~/.openclaw/`, in formats you can read, edit, version-control, and migrate. Nothing hidden in cloud state. The lobster molts; you keep the shell.
